Game Settings

Configure in-game admin scripts, mod call commands, and permissions for your experience.

Mod Call Command
This is the command players type in-game to request a moderator.
✓ Command saved successfully
Default command is Modcall Reason. Players will type this followed by their reason.
Admin Script Installation
Place this script in ServerScriptService. Requires admin permissions in the game. Requires Gamepass or Code
-- RoWave Admin Script (ServerScriptService) -- Default command: Modcall Reason local Players = game:GetService("Players") local HttpService = game:GetService("HttpService") local ReplicatedStorage = game:GetService("ReplicatedStorage") local MOD_COMMAND = "Modcall" -- Change this if you updated the command local WEBHOOK_OR_API = "YOUR_ROWAVE_API_URL_HERE" local function sendModCall(player, reason) local data = { userId = player.UserId, username = player.Name, displayName = player.DisplayName, reason = reason or "No reason provided", jobId = game.JobId, placeId = game.PlaceId } -- In production this would call your RoWave backend print("[RoWave] Mod call from", player.Name, ":", reason) -- HttpService:PostAsync(WEBHOOK_OR_API, HttpService:JSONEncode(data)) end Players.PlayerAdded:Connect(function(player) player.Chatted:Connect(function(message) local args = string.split(message, " ") if string.lower(args[1]) == string.lower(MOD_COMMAND) then local reason = table.concat(args, " ", 2) sendModCall(player, reason) end end) end) print("[RoWave] Admin script loaded")
How to Install
Follow these steps inside Roblox Studio
1

Open your game in Roblox Studio

Make sure you have edit permissions on the experience.

2

Insert a Script into ServerScriptService

Right-click ServerScriptService → Insert Object → Script. Name it “RoWaveAdmin”.

3

Paste the script above

Replace the entire contents of the new script with the code provided.

4

Update the command (optional)

If you changed the command in RoWave, also update the MOD_COMMAND variable in the script.

5

Publish the game

Save and publish so the script goes live for all servers.

Permissions & Requirements
Who can use these features
  • Only users with Admin or higher in the organization can edit Game Settings
  • Mod Call features require the Mod Management gamepass (ID: 1966224268) or the code WaveLinkOG129907
  • The in-game script must be placed by someone with edit access to the experience
  • HttpService must be enabled in Game Settings → Security if you later connect real webhooks
